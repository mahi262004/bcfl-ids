How one training round works

  1. Local trainingEach of the 9 IoT devices trains on its own traffic. Raw data never leaves the device.
  2. Trust gateThe server compares every update with the median update: direction (cosine) and size (norm ratio).
  3. Robust aggregationAccepted updates are combined with a trimmed mean, which discards extreme values per weight.
  4. On-chain recordScore, reputation, update hash and explanation hash go to the TrustLayer smart contract.
  5. ExplanationIntegrated Gradients shows which traffic features drove each alert.

What protects the model before training starts

Devices agree on a shared feature scale by exchanging only counts, sums and sums of squares. Each device gets one vote per feature, so a client that lies about its statistics cannot move the scale outside the honest range.
